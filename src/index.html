                     fly                     orbit
mouse                click to lock / look   press + drag canvas (cursor visible)
click (no drag)      select the star as orbit target (C cycles modes)
WASD / arrows        forward / strafe        W/S closer / farther, A/D circle
E / Q                local up / down         over / under
scroll               speed x2 per notch      distance x2 per notch
Shift / Ctrl         speed x100 / x0.1       rates x4 / x0.25
C                    camera: fly -> orbit galactic centre -> orbit object
P                    constellation lines on / off
H                    home: the Sun, or a generated galaxy's centre
G                    new galaxy: cycle type (rebuilds the field, about a second)
R                    reset everything
F                    fly to the selected star and orbit it
N / Shift+N          next / previous star in the selection (primary)
X                    clear the selection set
Shift+click          toggle a star in the selection (plain click selects it alone)
Esc                  release cursor in fly mode
Tab                  settings menu (releases cursor)
[ / ]                exposure (how faint a star still shows)
; / '                brightness (overall gain)
Ctrl+W closes the tab: fly slowly with Ctrl + arrows
