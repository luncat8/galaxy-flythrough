fly                     orbit
mouse drag / click   look (pointer lock)     circle the target
click (no drag)      select the star as orbit target (C C orbits it)
WASD / arrows        forward / strafe        W/S closer / farther, A/D circle
E / Q                up / down               over / under
scroll               speed x2 per notch      distance x2 per notch
Shift / Ctrl         speed x100 / x0.1       rates x4 / x0.25
C                    camera: fly -> orbit galactic centre -> orbit object
P                    constellation lines on / off
H                    home: the Sun (fly: teleport, orbit: circle it from 10 pc)
R                    reset everything
[ / ]                exposure (how faint a star still shows)
; / '                ACES gain (overall brightness)
Ctrl+W closes the tab: fly slowly with Ctrl + arrows
