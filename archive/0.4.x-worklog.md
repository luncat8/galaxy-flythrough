# 0.4.x Worklog

## 0.4.0 — kinematic star movement (initial implementation)

Implemented the first vertical slice from `0.4.0-plan-star-move.md`:

- Added `src/math/orbit.js` with four orbit families, rotation laws, CPU mirror, family packing helpers, precision-safe slider mapping, and the camera-coupled time gain.
- Reclaimed the existing 16-byte record's flags/jitter spare for orbit family, phase, and amplitude rank without changing buffer size.
- Added the orbit transform to the wired star-sprite shader. The existing time uniform now carries global star time, and the model centre is uploaded without adding a binding.
- Added a live star-time slider (`-1` follow through `99` Myr/s), exact frozen mode, `T` freeze/resume, epoch wrapping, and overlay reporting.
- Routed landmarks, labels, and picking through the CPU orbit mirror so named stars move with the GPU field.
- Added page wiring and parity coverage for `OrbitLib`.

Validation: `all-tests` passes apart from no remaining failures after the browser namespace fix; export parity, M1 smoke, and WGSL validation pass. Remaining 0.4 work is the full per-type dynamics/amplitude calibration, catalog/object family tagging, numerical orbit tests, and browser visual tuning.
